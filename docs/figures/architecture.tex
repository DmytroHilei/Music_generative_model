\path let \p1 = (why.south), \n1 = {min(\y1 - 0.9cm, 11.25cm)} in coordinate (Rtop) at (5.4, \n1);
\node[anchor=north west, text width=9.2cm, ptext, inner sep=9pt] (rec) at (Rtop) {%
Without these measures the model follows the first section's caption and then ignores later ones.\\[5pt]
\textbf{1. Change-aware captions.} Each section caption names what changed since the section before
(\capt{drums enter, louder}). Half of the training windows contain a section change.\\[5pt]
\textbf{2. Spliced windows (50\% of windows).}\\[2pt]
\usebox{\spliceBox}\\[2pt]
File A up to a section boundary, then a section of file B (dashed) with B's caption and no file caption: the caption
contradicts the context and has to win.\\[5pt]
\textbf{3. Caption repeated every 64 notes,} in training and in generation.\\[2pt]
\usebox{\repeatBox}\\[2pt]
The same 4 section vectors are inserted again, so the caption is never far back in the context.\\[5pt]
\textbf{4. Section words from section statistics.} Loudness, pace and register words use thresholds over sections, not
whole files (\capt{loud} = the loudest 20\% of sections), and pace is split into rhythm (onsets per second) and texture
(notes per onset), so a section caption does not push the music to extremes.\\[5pt]
\textbf{5. Caption dropout $\to$ guidance.} File captions are replaced by null vectors 15\% of the time, section
captions 20\%, so generation can use classifier-free guidance \rcite{9} with scale 2.\\[5pt]
\textbf{Evidence so far} (107M pilot, one seed). Switch test: 6 prompt pairs A/B (e.g. soft / loud),
16 samples each, the section caption changes at note 1,024, guidance 2. The matching attribute (velocity, notes per
second, register, drum or string share) is measured per 256 notes; the score is its change after the switch divided
by its offset before it (0 = keeps the first style, 1 = a full flip; single prompts reach 1.5). The start model
v2\_A0: 0.01. 1,500 more steps without measures 2--4 (control): \textbf{0.06}, held-out NLL 2.772; splice alone 0.59,
repeat alone 0.09. The recipe above (2,700 steps): \textbf{0.98}, NLL 2.757. Tested and not used: a counterfactual
loss \rcite{8} (the true caption must beat the previous one by 0.05 nats on the changed section's first 32 notes):
alone 0.13, with splice and repeat 0.85 (0.94 with the section words above), at 1.8$\times$ the step time (a second
forward). Open cost: holding a caption still overshoots: asked for strings, 34\% of samples run away (6.8 notes
per onset; 24\% and 2.0 with the counterfactual loss). No error bars yet.};

  by a PCA of their outputs weighted by the output projection, and the key heads per RoPE rotation pair by a rank-1
  complex merge weighted by the query energy, so RoPE stays exact. Measured on 16 batches of the model's own inputs.\\[4pt]
  \textbf{Transfer.} 300 steps in which only the attention layers train, each to reproduce its own full-attention output
  (relative MSE) on the original layer inputs, LR $10^{-3}$; the rest of the model is frozen.\\[4pt]
  \textbf{Result.} After 1,500 steps: mean-pool $+0.200$ vs full attention, merge only $+0.069$, merge + transfer
  $+0.040$ and still closing. F1 converts the 450M the same way (18 $\to$ 6 heads) and trains $\approx$30$\times$ longer.};
