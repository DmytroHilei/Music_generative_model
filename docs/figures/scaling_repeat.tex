% Repeat penalty in the RTX 5090 scaling runs (20-22 Nov 2026): held-out CE with repeated data minus CE with fresh data,
% same model and notes seen. (a) against model size at 3.9 passes over 41.5M unique notes: the default recipe with
% random windows, the tuned recipe (weight decay 1.0 + dynamics + instrument family), even epochs (iso #26 - #24);

% noise (none where one side has one seed). Data: python tools/sweeps/scaling_figs.py
% (docs/figures/scaling_data/rep_*.dat, from results/aug_sweep/runs.json and results/isoflop/runs.json).
